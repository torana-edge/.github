## Your coding agent. Now programmable.

Torana sits between your AI coding agent (Claude Code, Codex, Gemini or any
other) and the model. Hook into every step with sandboxed plugins. It runs
locally, with no account.

Install on macOS or Linux:

```bash
curl -fsSL https://torana.sh/install.sh | sh
```

On Windows, see the [quickstart](https://torana.sh/quickstart/) for the PowerShell installer.

- **Catch leaked secrets.** Your agent read your secrets. Your model doesn't have to.
- **See your usage.** Log providers, latency and tokens without storing prompts.
- **Write your own rules.** Build a plugin once in Go or Rust and bring it to every coding agent.
